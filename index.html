让对比更顺手

双击 index.html 或启动脚本即可打开，无需安装、账号或网络。

  • 粘贴文本，或将文件拖入 A / B 任一输入区。导入上限为每侧 5 MB，文本上限为每侧 200 万字符、10 万行。
  • 乱码时先选择正确编码，再重新导入。支持 UTF-8、GBK / GB18030 和 UTF-16；不支持 PDF、Word、Excel 等二进制文档。
  • 默认实时对比。关闭后使用“开始对比”或 Ctrl + Enter。差异导航支持 Alt + ↑ / ↓，输入区内不会拦截光标快捷键。
  • 忽略所有空白会忽略行内空格和制表符；空白行、行的顺序和末尾换行仍参与比较。CRLF / LF 统一处理。
  • 勾选“在此浏览器保留文本”后，文本存入本地浏览器；取消勾选或清空时立即删除。默认不保存文本，其他人使用同一浏览器可能看到已保留文本。
  • 导出的是独立 HTML 对比报告，可离线打开。大量内容分批显示，差异跳转会自动加载对应行。
