# 验证记录

日期：2026-10-21。测试使用内置示例与合成文本。

## 自动验证

- `npm test`：10 项 Node 测试，覆盖差异算法和 WebView2 桥接。
- 差异算法包括 2,000 组确定性随机输入，与独立 LCS 算法验证最小编辑成本及左右内容重建。
- 50,000 行稀疏修改与 3,000 行完全不同输入验证有界降级不丢失内容。
- 桥接测试验证主文档来源限制、请求响应关联、取消与错误、菜单动作白名单、原生文件字节传输；页面不能指定原生文件读取路径。
- `npm run desktop:package`：Windows PowerShell 构建，校验固定版本 WebView2 SDK 的 SHA-256，并运行 C# 来源和报告参数校验。

## 已完成的桌面验证

- Windows 上从 EXE 启动，加载系统 WebView2 Runtime 154.0.4258.53；本机 .NET Framework Release 为 533509。
- 内置示例得到 2 处差异、3 行修改、1 行新增，Worker 和行内高亮正常。
- Ctrl+O 使用 Windows 原生文件选择器导入 UTF-8 中文文件，文件名与内容正常显示。
- Ctrl+Shift+S 使用原生另存为导出 HTML，核对报告差异统计、文件名及脚本转义。
- 重复启动只保留一个应用主进程。
- Windows ZIP 的 CRC、必要文件及实际 EXE 一致性检查。

## 边界

尚未在其他电脑或缺少运行组件的系统上完成实测，也未执行物理断网测试。文件拖放、跨会话文本保留和快捷方式脚本尚未单独执行 WebView2 端到端测试。源码的外部请求拦截和 CSP 不等同于上述环境的实测。

发行包不含系统共享的 WebView2 / .NET 运行时；应用 Profile 和缓存也不计入 ZIP 体积。当前为未签名便携版。
